## Задания на закрепление

Используйте встроенный раннер: создавайте `*.test.mjs` и запускайте `node --test`.

### Задание 1. Первые тесты

Напишите функцию `slugify(str)` (нижний регистр, пробелы и спецсимволы → `-`, без дублей и дефисов по краям) и **сначала тесты** на неё (TDD): обычная строка, лишние пробелы, спецсимволы, пустая строка, кириллица (оставить как есть или транслитерировать — решите и зафиксируйте тестом).

### Задание 2. Асинхронный код и ошибки

Протестируйте функцию `parseJsonFile(path)`, которая читает файл и разбирает JSON. Покройте: корректный файл, несуществующий файл (`ENOENT`), некорректный JSON. Используйте `assert.rejects` и временный каталог (`fs.mkdtemp`) с очисткой в `after`.

### Задание 3. Моки и внедрение зависимостей

Дан сервис:

```js
export class NotificationService {
  constructor({ mailer, userRepo }) { this.mailer = mailer; this.userRepo = userRepo; }
  async notify(userId, text) {
    const user = await this.userRepo.findById(userId);
    if (!user) throw new Error("User not found");
    if (!user.email) return false;
    await this.mailer.send(user.email, text);
    return true;
  }
}
```

Напишите тесты (с `mock.fn`) на три сценария: отправка письма, пользователь без email (письмо не отправляется), пользователь не найден. Проверьте число вызовов и аргументы.

### Задание 4. Время под контролем

Реализуйте `debounce(fn, ms)` и протестируйте его с `mock.timers` без реального ожидания: три быстрых вызова → одно срабатывание после `ms`; вызов после паузы срабатывает отдельно; аргументы последнего вызова передаются в `fn`.

### Задание 5. Интеграционный тест HTTP

Возьмите API из темы про REST (todo) и напишите интеграционные тесты: сервер на случайном порту (`listen(0)`), проверки `POST /todos` (201 и `Location`), `GET /todos/:id`, валидация (422), несуществующий id (404). Серверы закрывайте в `after`, тесты независимы.

### Задание 6. Flaky-тест

Почему этот тест нестабилен? Исправьте так, чтобы он был детерминированным и быстрым.

```js
test("кэш протухает через 1 секунду", async () => {
  const cache = new TtlCache(1000);
  cache.set("a", 1);
  await new Promise((r) => setTimeout(r, 1000));
  assert.equal(cache.get("a"), undefined);
});
```

За 2 минуты расскажите: *«Как вы выстраиваете тестирование нового backend-сервиса на Node.js?»* Упомяните: пирамиду, границы моков, БД в тестах, CI, покрытие.
