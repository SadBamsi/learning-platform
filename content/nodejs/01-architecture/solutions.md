## Решения

### Задание 1

```js
import http from "node:http";

http
  .createServer((req, res) => {
    if (req.url === "/block") {
      const end = Date.now() + 3000;
      while (Date.now() < end) {} // синхронная блокировка главного потока
    }
    res.end(`ok ${req.url}\n`);
  })
  .listen(3000);
```

`/fast`, вызванный во время `/block`, ответит только **после** завершения `/block` (около 3 секунд). Event loop занят выполнением синхронного цикла и не может принять и обработать новое событие. Ровно поэтому один «тяжёлый» запрос замораживает сервер для всех клиентов.

### Задание 2

```js
import crypto from "node:crypto";

const start = Date.now();
for (let i = 1; i <= 8; i++) {
  crypto.pbkdf2("pwd", "salt", 600_000, 64, "sha512", () => {
    console.log(`#${i} завершён через ${Date.now() - start} мс`);
  });
}
```

С размером пула по умолчанию (4) задачи завершаются **двумя волнами**: первые четыре примерно за T, остальные четыре примерно за 2T. С `UV_THREADPOOL_SIZE=8 node pool.js` все восемь идут параллельно и завершаются примерно за одно и то же время (при условии, что хватает физических ядер). Конкретные числа зависят от машины; важна именно картина «две волны» против «одной».

### Задание 3

1. `fs.promises.readFile` — **да** (пул потоков).
2. `http.get` — **нет**: неблокирующий сокет, события приходят от ОС (epoll/kqueue/IOCP).
3. `crypto.randomBytes(32, cb)` — **да** (асинхронный вариант идёт в пул).
4. `dns.lookup` — **да**, использует системный `getaddrinfo` в пуле. (А `dns.resolve*` ходит в сеть напрямую и в пул не идёт.)
5. `zlib.gzip` (асинхронный) — **да**.
6. `fs.readFileSync` — **ни то ни другое**: выполняется синхронно прямо в главном потоке и блокирует его.

### Задание 4

```js
import os from "node:os";

const mb = (bytes) => Math.round(bytes / 1024 / 1024);

console.log({
  os: `${os.type()} ${os.release()} (${os.platform()}/${os.arch()})`,
  cpus: os.availableParallelism(), // или os.cpus().length
  freeMemMB: mb(os.freemem()),
  totalMemMB: mb(os.totalmem()),
  node: process.version,
  pid: process.pid,
});
```

`os.availableParallelism()` — метод, предназначенный именно для выбора числа параллельных задач/воркеров; `os.cpus().length` просто возвращает число найденных логических CPU.

### Задание 5

Пример хорошего ответа:

«JS-код в Node.js выполняется в одном главном потоке, где крутится event loop. Но он не ждёт операции ввода-вывода: сеть обслуживает ядро ОС через epoll/kqueue/IOCP, а libuv сообщает о готовых событиях; файловые операции, DNS-lookup, криптография и сжатие уходят в пул потоков libuv (по умолчанию 4 потока). Когда операция завершена, её колбэк возвращается в главный поток. Благодаря этому один поток обслуживает тысячи соединений без затрат на поток-на-соединение. Ограничение: CPU-bound код блокирует event loop, поэтому тяжёлые вычисления выносят в worker threads, отдельные процессы или сервисы».
