## Задания на закрепление

### Задание 1. Что не так?

Найдите проблемы в каждом фрагменте и исправьте.

```jsx
// а)
<input value={name} />

// б)
const [age, setAge] = useState();             // undefined
<input value={age} onChange={(e) => setAge(e.target.value)} />

// в)
function Form() {
  const [email, setEmail] = useState("");
  return (
    <form onSubmit={() => save(email)}>
      <input value={email} onChange={(e) => setEmail(e.target.value)} />
      <button>OK</button>
    </form>
  );
}
```

### Задание 2. Управляемая форма с валидацией

Форма регистрации: email, пароль (минимум 8 символов), подтверждение пароля. Ошибка поля показывается после ухода с него (`touched`) или после первой попытки отправки; кнопка блокируется на время отправки. Реализуйте на `useState`. Сколько рендеров на ввод 3 символов? Как сократить их число?

### Задание 3. Та же форма через action

Перепишите форму из задания 2 на `<form action>` + `useActionState`: ошибки приходят из функции действия, введённые значения сохраняются при ошибке, при успехе форма очищается. Почему без `defaultValue` из состояния пользователь потерял бы ввод?

### Задание 4. Кнопка с pending

Сделайте компонент `SubmitButton`, который сам знает, что форма отправляется. Почему он не работает, если вызвать `useFormStatus` в компоненте, который **содержит** `<form>`?

### Задание 5. Оптимистичный список

Список задач: пользователь добавляет задачу, она должна сразу появиться с пометкой «отправляется…»; после ответа сервера пометка исчезает; если сервер вернул ошибку — задача пропадает. Реализуйте через `useOptimistic`.

### Задание 6. Двойная отправка

Назовите три слоя защиты от двойной отправки формы (клиент, сеть, сервер) и реализуйте клиентскую.
