## Задания на закрепление

### Задание 1. Поймает ли граница?

Для каждого случая: попадёт ли ошибка в ближайший `ErrorBoundary`? Что увидит пользователь?

```jsx
// а) ошибка в рендере
function A() { throw new Error("render"); }

// б) ошибка в обработчике
function B() { return <button onClick={() => { throw new Error("click"); }}>x</button>; }

// в) ошибка в useEffect (синхронная)
function C() { useEffect(() => { throw new Error("effect"); }, []); return null; }

// г) ошибка в промисе внутри эффекта
function D() { useEffect(() => { fetch("/bad").then(() => { throw new Error("then"); }); }, []); return null; }

// д) ошибка в async-функции внутри startTransition
function E() {
  const [, start] = useTransition();
  return <button onClick={() => start(async () => { await save(); throw new Error("save"); })}>x</button>;
}

// е) отклонённый промис в use()
function F({ promise }) { return <b>{use(promise)}</b>; }
```

### Задание 2. Своя граница

Напишите класс `ErrorBoundary` с пропсами `fallback({ error, reset })` и `onError(error, componentStack)`. Продемонстрируйте, что соседний компонент вне границы продолжает работать, а кнопка «Повторить» восстанавливает интерфейс после исправления причины.

### Задание 3. Ошибки из асинхронного кода

Напишите хук `useThrowAsync()`, пробрасывающий ошибку из промиса в ближайшую границу. Затем покажите второй способ: через `startTransition`. Когда лучше показать ошибку на месте (через состояние), а когда отправить в границу?

### Задание 4. Retry при смене данных

Страница профиля: при смене `userId` граница должна сбрасываться сама. Реализуйте через `resetKeys` (своя реализация или `react-error-boundary`). Что произойдёт при повторном рендере с тем же `userId` после ошибки?

### Задание 5. Расставить границы

Для приложения (шапка, меню, лента новостей, виджет погоды, чат) предложите схему границ и fallback'ов. Что покажет приложение, если упадёт погода? А если упадёт шапка?

### Задание 6. Логирование

Какие данные отправите при ошибке, что нельзя отправлять и как поймать ошибки, не попавшие ни в одну границу? Как использовать опции `createRoot`?

### Задание 7. Устно

1. Почему границы ошибок — классовые компоненты?
2. Что происходит с деревом, если ошибка рендера никем не поймана?
3. Почему `try/catch` вокруг `<Child />` не защищает от ошибок в `Child`?
