## Задания на закрепление

### Задание 1. ref или state?

Для каждого случая выберите `useState` или `useRef` и объясните: (а) id `setTimeout`; (б) значение поля формы, которое нужно показывать в превью; (в) DOM-узел `<canvas>`; (г) число отрисовок компонента для отладки; (д) «пользователь уже кликал» для аналитики, не влияющей на UI; (е) выбранная вкладка.

### Задание 2. Что на экране?

Нажимаем кнопку дважды. Сколько рендеров будет и что отобразится? Затем замените `ref` на `state` и повторите.

```jsx
function Counter() {
  const count = useRef(0);
  return <button onClick={() => { count.current += 1; }}>{count.current}</button>;
}
```

### Задание 3. Автофокус и прокрутка

Напишите компонент чата: список сообщений, поле ввода и кнопка «Отправить». После отправки поле очищается и получает фокус, а список прокручивается к последнему сообщению. Какой хук нужен для прокрутки и почему именно он?

### Задание 4. Компонент с узким API

Сделайте `TextInput`, который родитель может вызывать как `ref.current.focus()` и `ref.current.clear()`, но не может, например, поменять `className` через `ref.current`. Реализуйте без `forwardRef` (React 19) и дополнительно покажите вариант через `forwardRef`.

### Задание 5. Секундомер

Реализуйте секундомер с кнопками «Старт», «Стоп», «Сброс». Повторные клики по «Старт» не должны создавать второй интервал; при размонтировании интервал должен очищаться. Где хранить id интервала?

### Задание 6. usePrevious

Напишите `usePrevious(value)` и объясните, почему во время рендера он возвращает **предыдущее** значение, а не текущее. Покажите вывод для последовательности значений `1 → 2 → 2 → 3`.

### Задание 7. Измерение размеров

Напишите хук `useElementWidth()`, возвращающий `[ref, width]`: ширина обновляется при изменении размера элемента (`ResizeObserver`). Используйте callback ref с cleanup. Что произойдёт, если сделать callback ref без `useCallback`?

### Задание 8. Баг с ref в рендере

Найдите проблему и исправьте:

```jsx
function List({ items }) {
  const renders = useRef(0);
  renders.current += 1;
  return <div><p>Рендеров: {renders.current}</p>{items.map((i) => <li key={i}>{i}</li>)}</div>;
}
```
