## Задания на закрепление

### Задание 1. План диагностики

Пользователи жалуются: «страница с таблицей на 5000 строк тормозит при вводе в поле фильтра, а первая загрузка долгая». Составьте пошаговый план: что и чем измеряете, какие гипотезы проверяете, в каком порядке, как убеждаетесь, что стало лучше.

### Задание 2. Profiler в коде

Оберните часть интерфейса в `<Profiler>` и выведите в консоль для каждого коммита: фазу, `actualDuration`, `baseDuration`. Что означает ситуация, когда `actualDuration` сильно меньше `baseDuration`? А когда они почти равны при частых обновлениях?

### Задание 3. Виртуализация

Реализуйте список из 1000 элементов с фиксированной высотой строки 20 px и областью просмотра 100 px, который держит в DOM только видимые строки (+ небольшой запас). Проверьте: сколько строк в DOM в начале и после прокрутки на 5000 px.

### Задание 4. Lazy и упреждающая загрузка

Тяжёлый компонент `Editor` нужен только после клика «Редактировать». Загружайте его лениво, показывайте индикатор на время загрузки, а загрузку начинайте уже при наведении на кнопку.

### Задание 5. Высокочастотные события

Компонент показывает координату мыши и пересчитывается на каждое `mousemove`. Покажите три способа уменьшить работу: (а) обновлять DOM через `ref`, (б) ограничить частоту через `requestAnimationFrame`, (в) вынести визуальный эффект в CSS-переменную. Сколько рендеров будет в варианте (а)?

### Задание 6. Найти проблемы

Перечислите минимум пять проблем производительности в коде и исправления:

```jsx
function Table({ rows }) {
  const [query, setQuery] = useState("");
  const [filtered, setFiltered] = useState(rows);
  useEffect(() => {
    setFiltered(rows.filter((r) => r.name.includes(query)));
  }, [rows, query]);

  const Cell = ({ value }) => <td>{value}</td>;

  return (
    <>
      <input value={query} onChange={(e) => setQuery(e.target.value)} />
      <table>
        <tbody>
          {filtered.map((r, i) => (
            <tr key={i} onClick={() => select(r)}>
              <Cell value={r.name} />
              <Cell value={r.price} />
            </tr>
          ))}
        </tbody>
      </table>
    </>
  );
}
```
